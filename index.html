Quick start

  1. Choose a proxy product and location in your dashboard.
  2. Choose HTTP(S) or SOCKS5 and copy the generated endpoint.
  3. Set it as SOCKSNODE_PROXY in your shell or secret manager.
  4. Run one of the examples below and verify against a destination you control.
Mobile locations and bandwidth options depend on the selected tier. Allowances reset at 00:00 UTC; unused daily allowance does not carry over. Check the live mobile proxy details for current prices and limits.

Endpoint format

# SOCKS5 (use socks5h where supported to proxy DNS lookups)
export SOCKSNODE_PROXY='socks5h://USERNAME:PASSWORD@HOST:PORT'

# Or an HTTP proxy endpoint
export SOCKSNODE_PROXY='http://USERNAME:PASSWORD@HOST:PORT'

Copy the real endpoint from your dashboard. If a credential contains reserved URL characters, percent-encode its username and password components. Never commit real credentials.

Use a proxy with Python Requests

Install Requests with SOCKS support if you plan to use a SOCKS5 endpoint:

python -m pip install 'requests[socks]'
import os
import requests

proxy = os.environ["SOCKSNODE_PROXY"]
response = requests.get(
    "https://api.ipify.org",
    proxies={"http": proxy, "https": proxy},
    timeout=30,
)
response.raise_for_status()
print(response.text)

Use an HTTP proxy with Playwright

Playwright accepts HTTP proxy credentials as separate launch options. Copy the HTTP endpoint from your dashboard and set the username and password as environment variables.

Python

Install Playwright using its official setup guide, then pass the HTTP proxy and credentials when launching Chromium.

import asyncio
import os
from urllib.parse import urlsplit
from playwright.async_api import async_playwright

async def main():
    endpoint = urlsplit(os.environ["SOCKSNODE_PROXY"])
    if endpoint.scheme not in {"http", "https"}:
        raise ValueError("Use an HTTP proxy endpoint for this example")
    server = f"{endpoint.scheme}://{endpoint.hostname}:{endpoint.port}"
    async with async_playwright() as p:
        browser = await p.chromium.launch(proxy={
            "server": server,
            "username": os.environ["SOCKSNODE_USERNAME"],
            "password": os.environ["SOCKSNODE_PASSWORD"],
        })
        page = await browser.new_page()
        await page.goto("https://example.com", wait_until="domcontentloaded")
        print(await page.title())
        await browser.close()

asyncio.run(main())

Node.js

Set the proxy in the browser launch options. Install Playwright and Chromium using the official setup guide.

import { chromium } from "playwright";

const endpoint = new URL(process.env.SOCKSNODE_PROXY);
if (!["http:", "https:"].includes(endpoint.protocol)) {
  throw new Error("Use an HTTP proxy endpoint for this example");
}
const server = `${endpoint.protocol}//${endpoint.hostname}:${endpoint.port}`;
const browser = await chromium.launch({
  proxy: {
    server,
    username: process.env.SOCKSNODE_USERNAME,
    password: process.env.SOCKSNODE_PASSWORD,
  },
});
try {
  const page = await browser.newPage();
  await page.goto("https://example.com", { waitUntil: "domcontentloaded" });
  console.log(await page.title());
} finally {
  await browser.close();
}

Credentials and responsible use

  • Keep usernames, passwords, and API keys in environment variables or a secret manager.
  • Do not put working credentials in repositories, screenshots, issue reports, or client-side public code.
  • Respect destination-site terms, access controls, privacy requirements, and applicable law.
  • Proxy availability and third-party website behavior can change; examples do not guarantee a destination will accept a request.
